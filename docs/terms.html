Personal Wellness Journal — незалежний некомерційний проєкт для особистих спостережень за самопочуттям та звітів українською.

1. Призначення і поточний стан

Проєкт підтримує власник GitHub-акаунта fedak для власного використання. Публічний сайт містить інформаційні сторінки. Окремий локальний клієнт на Mac власника підключається до Oura, зберігає доступні дані та показує персональні графіки й звіти українською.

Сайт можна переглядати без реєстрації та оплати. Підписок, платних функцій або приймання платежів немає. Строк запуску майбутніх можливостей не гарантується.

2. Доступ до даних

Персональний клієнт призначений для даних власника проєкту та потребує його явної авторизації в Oura. Не можна використовувати чужі облікові дані або отримувати доступ до інформації іншої людини без належного дозволу. Авторизацію можна відкликати в налаштуваннях інтеграцій Oura.

Обробку даних описує політика конфіденційності. Увімкнення нових способів обробки потребуватиме відповідного оновлення політики.

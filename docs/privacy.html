Зараз це статичний інформаційний сайт. Він не підключений до вашого акаунта Oura, не запитує показники здоров’я та не передає їх у системи ШІ.

1. Проєкт і відповідальна особа

Personal Wellness Journal — персональний некомерційний проєкт, який підтримує власник GitHub-акаунта fedak. Ця політика описує роботу поточного сайту та запланованого локального клієнта для власних даних його власника. Реєстрація інших користувачів наразі не передбачена.

2. Дані під час відвідування сайту

Сайт не містить форм, рекламних модулів, аналітичних трекерів, сторонніх шрифтів або вбудованого вмісту. Код сайту не встановлює cookies і не використовує сховище браузера. Просто відкривши сторінку, ви не надаєте проєкту доступу до Oura.

Сторінки розміщені на GitHub Pages. GitHub отримує технічні дані вебзапитів і повідомляє, що реєструє IP-адреси відвідувачів для безпеки. Обробка цих даних і строки їх зберігання регулюються політикою конфіденційності GitHub. Власник проєкту не керує журналами хостингу.

3. Запланована інтеграція з Oura

Інтеграція ще не реалізована. Для майбутнього локального клієнта передбачено отримання даних лише після явної авторизації власника через OAuth2 Oura. Пароль Oura має вводитися виключно на сторінці Oura.

Залежно від наданих дозволів клієнт може запитувати показники сну, активності, готовності, пульсу та HRV, SpO₂, стресу, здоров’я серця, тренування й теги. Дані профілю та сесій можуть запитуватися лише якщо відповідні функції буде додано та власник надасть дозвіл. Мета — особисті графіки, порівняння періодів і звіти українською.

4. Зберігання, доступ і видалення

Поточний сайт не має бази показників здоров’я й не зберігає токени Oura. Запланована перша версія клієнта працюватиме на комп’ютері власника: отримані для звіту дані оброблятимуться в пам’яті протягом сеансу, без автоматичного постійного архіву. Облікові дані доступу зберігатимуться локально з обмеженим доступом, поза публічним репозиторієм і сайтом.

У майбутньому клієнті припинення обробки має бути доступним шляхом його зупинки та відкликання доступу в налаштуваннях інтеграцій Oura. Локальні токени можна буде видалити. Якщо буде додано збереження звітів чи історії, перед запуском цієї функції тут буде описано місце, строк зберігання та порядок видалення.

5. Передавання даних і ШІ

Зараз у проєкті немає підключених ШІ-провайдерів або сервісів обробки показників здоров’я. Публічний сайт не продає та не передає такі дані. Посилання на GitHub і Oura ведуть на окремі сайти з власними правилами конфіденційності.

Якщо буде додано пояснення за допомогою ШІ або іншу зовнішню обробку, перед її ввімкненням політика буде оновлена: із зазначенням провайдера, набору переданих даних, мети, строків зберігання та доступних налаштувань приватності. Таке передавання потребуватиме окремого явного рішення власника та врахування застосовних умов Oura.

6. Звернення та зміни політики

Питання щодо проєкту можна залишити в GitHub Issues. Це публічний канал: не публікуйте там показники здоров’я, паролі або токени. Сам текст звернення обробляє GitHub за власною політикою. Зміни цієї сторінки позначатимуться новою датою; історія доступна в репозиторії проєкту.

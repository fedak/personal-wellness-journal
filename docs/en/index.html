What the journal offers

01 / OBSERVATION

Personal history

A local archive of Oura data, including battery history. The report shows sleep, heart rate, activity, and other metrics for the last 30 days.

02 / CONTEXT

Changes over time

Daily and weekly comparisons with the owner's previous measurements. Habit tags will help identify recurring associations.

03 / UNDERSTANDING

In Ukrainian

Charts, metric names, and explanations in the owner's native language. Reports show which data support each observation.

Current status

This is an informational website for a private, non-commercial project. A separate client runs on the owner's Mac: it synchronizes all 19 supported Oura data types, stores history locally, and generates reports in Ukrainian. The website does not accept health data, offer account sign-in, or generate personal insights. More about data handling.

# Personal Wellness Journal

Інформаційний сайт персонального некомерційного проєкту для аналізу власних
показників Oura та звітів українською. Окремий приватний клієнт уже працює на Mac власника та зберігає доступні дані Oura локально.

## Публічні сторінки

Українською:

- Конфіденційність: https://fedak.github.io/personal-wellness-journal/privacy.html
- Умови: https://fedak.github.io/personal-wellness-journal/terms.html

Англійською (для форми Oura):

- About: https://fedak.github.io/personal-wellness-journal/en/
- Privacy Policy: https://fedak.github.io/personal-wellness-journal/en/privacy.html
- Terms of Service: https://fedak.github.io/personal-wellness-journal/en/terms.html

Сайт — звичайні HTML і CSS без JavaScript, зовнішніх шрифтів, трекерів і залежностей.
Кожна сторінка має повні українську й англійську версії. Перемикач УКР / EN
відкриває відповідний документ іншою мовою; навігація зберігає вибрану мову.
Мова визначається URL без автоматичних перенаправлень, cookies чи JavaScript.
Доступні мобільна версія, навігація клавіатурою та стилі друку.

Під час зміни текстів оновлюйте обидві мовні версії й однакову дату документів.

## Локальний перегляд

```sh
python3 -m http.server 8080 --bind 127.0.0.1 --directory docs
```

Відкрити http://127.0.0.1:8080/ у браузері.

## Публікація

GitHub Pages публікує папку `/docs` із гілки `main`.
Після зміни файлів і push у `main` GitHub оновлює сайт автоматично.
Власний домен і платний хостинг не потрібні.

Цей репозиторій публічний і призначений лише для інформаційного сайту.
Код приватного клієнта, БД SQLite, резервна копія, токени та журнали зберігаються
в `.local/oura-client/` усередині цього проєкту. Ця папка виключена з Git.
Не переносьте файли клієнта або дані за межі папки проєкту. Не додавайте токени,
секрети, експорти даних або особисті звіти до публічного репозиторію.
GitHub Pages не є сервером OAuth і не обробляє callback авторизації.

## Перед підключенням даних

Політика описує статичний сайт та окремий локальний клієнт: постійний архів
повних відповідей API, записів і спостережених версій у SQLite, синхронізацію
приблизно кожні 30 хвилин, поки клієнт запущений, та щоденну копію в проєкті. Архів зберігається
до видалення власником. Публічний сайт не отримує цих даних. Перед додаванням
зовнішнього ШІ-провайдера або інших користувачів оновіть політику відповідно
до фактичної обробки даних.

Налаштування форми Oura наведені в [REGISTRATION.md](REGISTRATION.md).
